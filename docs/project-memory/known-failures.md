# Known Failures and Uncertainties

- The source-PDF write contract is resolved: ordinary annotation edits and Export PDF remain non-destructive, while explicit Add/Delete/Import/Scan page actions use `app.vault.modifyBinary` through `writePdfAndAnnotationStoresAtomic` and remap sidecar/recovery data. Live Obsidian host compatibility for those private viewer reloads remains unverified.
- Runtime compatibility of the plugin-owned direct PDF viewer and native-toolbar bridge against current Obsidian desktop, Android, and iPad builds remains unverified. The observed desktop host is Obsidian 1.14.4; private toolbar/registry contracts may change. Toolbar-constructor capture failures are logged during plugin load and shown when an owned PDF is opened; registry incompatibility remains a visible load failure because the plugin cannot claim PDF ownership safely.
- Circular erasing on very dense pages needs device profiling. Lasso resize and clipboard behavior need large-document profiling.
- Editable PDF annotation support varies by the PDF viewer; the vault sidecar remains the canonical editable data.
- The generated `main.js` bundle is approximately 1.73 MB (1,726,801 bytes) under the 2,200,000-byte budget because BRAT installs only `main.js`, `manifest.json`, and `styles.css`; the pinned PDF.js/pdf-lib/runtime dependencies are bundled and PDF.js runs in self-contained fake-worker mode. Current Obsidian desktop/mobile compatibility remains unverified.
